## Search discipline

Search the smallest plausible surface first. Identify the likely repository, directory, or file before searching; prefer explicit paths, `rg --files` with targeted globs, and scoped `git grep`/`git ls-files`. Start with filenames or known symbols, then widen only when narrower searches fail and evidence justifies it. Avoid unbounded repository/home recursion and exclude dependencies, `.git`, build outputs, caches, and generated files. Bound matches/output with `rg -l`, `rg -n`, `--max-count`, and targeted `-g` filters; don't pipe huge traversals into `head`. Use existing Git-aware tools where appropriate; never add heavyweight indexing or background scans. Broader discovery is allowed when necessary, but state the expanded scope and keep it resource-bounded.
